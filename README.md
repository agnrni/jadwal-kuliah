# 📅 Website Jadwal Kuliah Semester 5

Proyek halaman web statis untuk menampilkan jadwal perkuliahan harian mahasiswa **Teknik Informatika (Semester 5)** secara rapi, cepat, dan mudah dibaca melalui layar smartphone (*mobile-first design*).

## ✨ Fitur & Desain (UI/UX)
- **Mobile-First Container:** Tampilan berfokus pada ukuran layar smartphone (`max-width: 480px`) sehingga nyaman dilihat tanpa perlu *zoom in/out*.
- **Sticky Navigation Bar:** Navigasi hari (Senin–Kamis) tetap menempel di bagian atas layar saat halaman di-*scroll*.
- **Smooth Scrolling:** Perpindahan antar bagian hari berjalan halus saat tab hari diklik.
- **Informasi Terstruktur:** Setiap kartu jadwal menampilkan jam perkuliahan, kode ruangan, nama mata kuliah, dan dosen pengampu dengan hierarki visual yang jelas.

## 🛠️ Teknologi yang Digunakan
- **HTML5 Semantic** (`header`, `nav`, `main`, `section`, `article`)
- **CSS3** (Flexbox, Sticky Positioning, Custom Card Styling)
